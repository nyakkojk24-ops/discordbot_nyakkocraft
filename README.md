# discordbot_nyakkocraft

# 🐱 にゃっこBot (discordbot_nyakkocraft)

Discordサーバーで**料理・釣り・野菜収穫・図鑑コンプリート**などが遊べる、カジュアルRPG風エンタメBotです！
ボタンとドロップダウンで視覚的に操作でき、スマホからでも快適に遊べます。

---

## ✨ 主な機能

- 🎣 **釣りシステム**：様々な種類の魚を釣り上げ、最高記録を更新しよう！
- 🥗 **野菜収穫**：料理に必要な野菜や食材を収集！
- 🍳 **料理＆クラフト**：調理器具と食材を組み合わせて、新しいレシピを発見！
- 📖 **料理図鑑**：作った料理をコレクション。コンプリートを目指そう！
- 💰 **ショップ＆売却**：釣った魚や料理を売ってNPを獲得！
- 🌐 **マルチサーバー対応**：サーバーごとに個別データ（`data/[guild_id]/`）を完全分離保存！

---

## 📱 スマホ勢に優しい「ショートカットコマンド」

スラッシュコマンドを毎回探して打つ必要はありません！
チャット欄に **`にク`** （にゃっこクエスト）と送信するだけで、一瞬でメインメニューが開きます。

> **対応キーワード**: `にク` / `にく` / `ニク`

---

## 🎮 使い方

### 1. メインメニューの表示
チャットで `にク` と送信するか、`/start` コマンドを実行します。

### 2. メニューから遊ぶ
表示されたボタンを押すだけで簡単に遊べます：
- **[🎣 釣りをする]** : 魚を釣り上げる
- **[🥗 野菜収穫]** : 素材をゲット
- **[📦 インベントリ]** : 手持ちアイテムの確認
- **[🍳 料理をする]** : 調理・レシピ考案
- **[💰 魚を売る]** : NPを獲得
- **[📖 料理図鑑]** : レシピ一覧のチェック

---

## 🛠️ 技術スタック

- **Language**: Python 3.14+
- **Library**: `discord.py` (v2.0+)
- **Data Persistence**: JSON (Guild-based modular storage)
